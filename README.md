# Text Detector — OCR рукописного и печатного текста

Веб-приложение для распознавания текста на изображениях. Две модели YOLO находят слова на странице, локальная TrOCR распознаёт каждый фрагмент. Результат можно править в интерфейсе и экспортировать.

**Стек:** Python (Flask, YOLOv8, TrOCR), React + Vite + Tailwind CSS (собранный фронтенд в `dist/`)

---

## Что не входит в репозиторий

Из-за большого размера в Git **не хранятся**:

| Путь | Что это |
| :--- | :--- |
| `venv/` | Виртуальное окружение Python — создаётся локально при первом запуске |
| `text_recognition_model/model/` | Веса TrOCR (~сотни МБ) — скачиваются с Google Drive |

Перед запуском нужно **скачать модель** и положить её в нужную папку (см. [Модели](#модели)). Папку `venv/` создавать вручную не нужно — это сделает `start.bat`.

## Быстрый запуск (Windows)

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Скачайте модель TrOCR с Google Drive и распакуйте в `text_recognition_model/model/` (см. раздел [Модели](#модели)).
3. Убедитесь, что на месте веса YOLO в `segmentation best weight/`.
4. Запустите **`start.bat`** — скрипт создаст `venv` (если его ещё нет), **установит все Python-библиотеки**, поднимет бэкенд и фронтенд, откроет браузер.

| Сервис | Адрес |
| :--- | :--- |
| Интерфейс | http://localhost:3000 |
| API (Flask) | http://localhost:5000 |

После изменений во фронтенде обновите страницу с **Ctrl+F5**.

## Установка вручную

### Требования

* **ОС:** Windows (основной сценарий; Python-код можно запускать и на Linux/macOS)
* **Python:** 3.11+ (рекомендуется 3.11), добавлен в PATH
* **GPU:** необязательно; при наличии CUDA используется автоматически

### Шаги

1. Скачайте модель TrOCR (см. раздел [Модели](#модели)).
2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
pip install -r requirements.txt
```

> Папка `venv/` не коммитится в репозиторий — каждый пользователь создаёт её у себя локально. При запуске через `start.bat` окружение и библиотеки настраиваются автоматически.

Запуск в двух терминалах:

```bash
python app_v2.py
```

```bash
cd dist && python -m http.server 3000
```

## Модели

Перед первым запуском нужны файлы моделей — они **не** устанавливаются через `pip` и **не** лежат в репозитории (кроме весов YOLO, если они добавлены отдельно).

### YOLO (детекция слов)

Модель в папке `segmentation best weight/`:

| Файл | Назначение |
| :--- | :--- |
| `best_1.pt` | Основная модель детекции |

Без этого файла `app_v2.py` завершится с ошибкой при старте.

### TrOCR (распознавание текста)

Папка `text_recognition_model/model/` **не включена в репозиторий** из-за большого размера файла `model.safetensors`. Архив модели выложен на Google Drive:

**[Скачать модель TrOCR (Google Drive)](https://drive.google.com/drive/folders/1FnGtMwJS8_YOT6m_cdDhIEHUgMrCZFeJ)**


#### Куда положить файлы

1. Скачайте архив с Google Drive.
2. Распакуйте его так, чтобы в проекте получилась такая структура:

```
text_recognition_model/
└── model/
    ├── config.json
    ├── model.safetensors
    ├── tokenizer.json
    ├── tokenizer_config.json
    ├── processor_config.json
    └── generation_config.json
```

3. Проверьте, что путь совпадает: `text_recognition_model/model/config.json` существует относительно корня проекта.

Модель загружается **только из локальной папки** (`local_files_only=True`), без обращения к Hugging Face при работе. Без этих файлов `start.bat` и `app_v2.py` не запустятся.

## Возможности интерфейса

* Загрузка изображения и распознавание с настраиваемым **порогом уверенности** (по умолчанию 50 %)
* Подсветка слова на изображении при наведении на строку в панели «Расшифровка»
* **Двойной клик** — редактирование текста строки
* **Перетаскивание** — изменение порядка слов в расшифровке (drag-and-drop)
* Кнопка **«Рамка»** — ручная разметка пропущенных слов на изображении
* **Экспорт** — текст в одну строку, слова через пробел

## API бэкенда

Фронтенд отправляет запросы на `http://localhost:5000`.

### `POST /upload`

Принимает **multipart/form-data**:

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `file` | файл | Изображение (png, jpg, jpeg, gif, bmp, webp) |
| `conf` | число | Порог уверенности YOLO, 0.0–1.0 (по умолчанию `0.5`) |

**Ответ (200):**

```json
{
  "success": true,
  "text": "слово1 слово2 слово3",
  "image": "data:image/png;base64,...",
  "words_count": 3,
  "lines": [
    {
      "text": "слово1",
      "boundingBox": [100, 150, 120, 300]
    }
  ]
}
```

* `lines` — массив распознанных слов в порядке чтения
* `boundingBox` — координаты `[top, left, bottom, right]` в диапазоне **0–1000** (нужны для подсветки на изображении)
* `image` — исходник с нарисованными рамками в Base64

### `POST /download`

Скачивание текста как `.txt` (JSON-тело: `{ "text": "..." }`).

## Структура проекта

| Файл / папка | Описание |
| :--- | :--- |
| `start.bat` | Создание `venv`, установка зависимостей, запуск бэкенда и фронтенда |
| `app_v2.py` | Flask-сервер, эндпоинты `/upload` и `/download` |
| `text_detector.py` | Детекция (YOLO) + распознавание (TrOCR), пакетный inference |
| `functions.py` | Детекция YOLO, слияние двух моделей, сортировка боксов |
| `text_recognition_model/model/` | Локальные веса TrOCR |
| `segmentation best weight/` | Веса YOLO (`best_1.pt`) |
| `dist/` | Собранный React-интерфейс |
| `requirements.txt` | Python-зависимости |
| `download_weight.py` | Загрузка весов YOLO в `weights/` (устаревший путь; для приложения нужна папка `segmentation best weight/`) |

## Как это работает

1. Изображение поступает на Flask-сервер.
2. Две YOLO-модели находят слова; результаты объединяются и сортируются по порядку чтения.
3. Каждый кроп проходит предобработку (CLAHE, удаление горизонтальных линий) и распознаётся TrOCR пакетами по 16 изображений.
4. Фронтенд показывает список слов, рамки на картинке и позволяет править порядок и текст.

## Скрипты для офлайн-обработки

### `text_detector.py`

Сохранение найденных слов как отдельных изображений. Пути задаются в начале файла:

```python
example_images = 'text_detector/examples'
images_output = 'final_results'
words_output_dir = ''
```

### `download_weight.py`

Скачивает веса в `weights/best.pt` через Google Drive. Для веб-приложения используйте веса в `segmentation best weight/`.
